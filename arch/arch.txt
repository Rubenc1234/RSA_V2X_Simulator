Uma DENM (Decentralized Environmental Notification Message) não é apenas
"há um acidente aqui". É um EVENTO com identidade, duração, negação.

│       (stationId_sequenceNum_type) │
│                                     │

┌──────────────────────────────────────────────┐
│  DENM BURST (múltiplas publicações)         │
├──────────────────────────────────────────────┤
│                                              │
│  OBU detecta colisão (t=0s)                  │
│    ↓ start_collision_burst()                │
│                                              │
│  Entra em "modo transmissão" por 3s:        │
│  ├─ t=0.0s: PUBLICA DENM #1 (validity=10s) │
│  ├─ t=0.2s: PUBLICA DENM #2 (validity=9.8s)│ ← Desconto!
│  ├─ t=0.4s: PUBLICA DENM #3 (validity=9.6s)│ ← Desconto!
│  └─ ... a cada 0.2s até t=3.0s              │
│                                              │
│  Risco desaparece (t=3.2s)                   │
│    ↓ stop_collision_burst()                 │
│    └─ Cessa transmissão (sem negação!)      │
│                                              │
│  Receptores:                                 │
│  ├─ Recebem múltiplas cópias (redundância)  │
│  ├─ Sincronização automática via desconto   │
│  └─ Evento morre naturalmente via timeout    │
│                                              │

OPERAÇÕES:

1. RECEBER & PROCESSAR DENM
   ────────────────────────
    # Implementado em DENMRegistry.py:
    def register_denm_json(self, json_str: str) -> Optional[str]:
        """
        Consome JSON real do Vanetza.
        Registra evento com chave ETSI: "station_id:sequence_number"
        """
        payload = json.loads(json_str)
        
        # Extrai actionId (identificador único ETSI)
        orig_station = payload["fields"]["denm"]["management"]["actionId"]["originatingStationId"]
        seq_num = payload["fields"]["denm"]["management"]["actionId"]["sequenceNumber"]
        event_key = f"{orig_station}:{seq_num}"
        
        # Calcula expiração com desconto dinâmico:
        detection_time = payload["fields"]["denm"]["management"]["detectionTime"]
        validity_duration = payload["fields"]["denm"]["management"]["validityDuration"]
        expire_at = detection_time + validity_duration  # Sincronizado!
        
        # Regista
        self.active_events[event_key] = {
            "position": (lat, lon),
            "ccAndScc": {...},
            "expire_at": expire_at
        }

3. LIMPAR DENMS EXPIRADAS (periodic check, ex: 1Hz)
   ──────────────────────────────────────────────
   periodic_denm_cleanup():
       for denm_id, denm_data in registry.items():
           if now() > denm_data.expires_at:
               # DENM expirou, remove
               remove(denm_id) from registry
               cancel_action_for(denm_id)
               resume_normal_speed()


4. EVITAR DUPLICATAS DENM
   ───────────────────────
OBU1 (originadora):
  Waypoint 1 → Waypoint 2 (normal, speed=8.0 m/s)
  
  t=0.2s: detecta OBU2 a 18m
    ↓ start_collision_burst()
    ↓ PUBLICA DENM #1 (validity=10s)
  
  t=0.4s-3.0s: MANTÉM burst
    ├─ PUBLICA DENM #2 (validity=9.8s)
    ├─ PUBLICA DENM #3 (validity=9.6s)
    └─ ... (a cada 0.2s com desconto)
    └─ speed=0.0 (EMERGENCY_BRAKE)
  
  t=3.2s: OBU2 agora a 22m (distância > 20m)
    ↓ stop_collision_burst()
    ↓ Cessa transmissão (SEM negação!)
    ↓ speed retoma gradualmente
  
OBU2 (vizinha):
  Waypoint 1 → Waypoint 2 (normal, speed=8.0 m/s)
  
  t=0.2s: RECEBE DENM #1 de OBU1 (validity=10s)
    ↓ denm_registry.register_denm_json(...)
    ↓ expire_at = 0.2 + 10.0 = 10.2s
    ↓ EMERGENCY_BRAKE (dist < 15m)
    ↓ speed=0.0
  
  t=0.4s: RECEBE DENM #2 (validity=9.8s)
    ↓ expire_at = 0.4 + 9.8 = 10.2s ← MESMO TEMPO!
    ↓ Mantém speed=0.0
  
  t=10.2s: DENMs expiram (clean_expired_events)
    ↓ denm_registry.active_events vazio
    ↓ evaluate_behavioral_speed() retorna speed=desired (8.0 m/s)
    ↓ Resume normal
  
RESULTADO VISUAL:
  ✅ Ambos abrandam simultaneamente
  ✅ Ambos aceleram simultaneamente (depois do timeout)
  ✅ SEM mensagens de negação
  ✅ Sincronização automática via desconto

MODELAÇÃO DE CENÁRIOS (MELHORADOS)
Paradigma: Cenário = Comportamento + Parâmetros
Ideia-chave: Não hardcode if scenario == "collision".... Em vez disso:
scenario.yaml / scenario.py:
├─ Nome & descrição
├─ Waypoints dos veículos (reutilizável em qualquer local)
├─ Eventos a simular (colisão, acidente, etc)
│  └─ cada com: posição, duração, tipo, raio
└─ Comportamento global (generalista)

vehicle.behavior_config (herdado do cenário):
├─ collision_threshold_m: 20
├─ accident_stop_zone_m: 100
├─ accident_slow_zone_m: 500
└─ ...
